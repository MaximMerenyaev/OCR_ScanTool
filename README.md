# 📄 OCR Web-Service

Веб-сервис для обработки сканированных документов с применением OCR и мультимодальных нейросетевых моделей. Объединяет классический OCR и нейросетевое распознавание с функциями анализа структуры, извлечения таблиц, суммаризации и анализа текста — с возможностью полностью локального развёртывания.

---

## ✨ Возможности

- 🔍 **Два движка распознавания** — классический Tesseract OCR (быстрый) и мультимодальная модель Qwen2-VL (высокое качество)
- 📑 **Поддержка форматов** — изображения (JPEG, PNG, BMP, TIFF) и многостраничные PDF
- 🧩 **Анализ структуры документа** — автоматическое обнаружение блоков через DocLayout-YOLO
- 📊 **Извлечение таблиц** — экспорт в формат Markdown
- ✏️ **Работа с текстом** — редактирование, суммаризация (ruT5), анализ (статистика, ключевые слова, NER, тональность)
- 💾 **Экспорт и история** — выгрузка в TXT/DOCX, сохранение истории обработки
- 🔒 **Локальная обработка** — без передачи документов внешним сервисам

## 🛠️ Стек технологий

| Слой | Технологии |
|------|------------|
| **Backend** | Python 3.10+, FastAPI, Uvicorn, Jinja2 |
| **ML** | PyTorch, Transformers, Tesseract, Qwen2-VL, ruT5, DocLayout-YOLO, Natasha |
| **Обработка** | OpenCV, Pillow, pdf2image |
| **Frontend** | HTML5, CSS3, JavaScript (Vanilla JS) |

## 🚀 Запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск сервиса
uvicorn main:app --host 0.0.0.0 --port 8000
```

После запуска сервис доступен по адресу **http://localhost:8000/**, документация API — **/docs**.

> ⚠️ Для работы движка Qwen2-VL требуется GPU с ≥ 8 ГБ видеопамяти. При отсутствии GPU доступен классический OCR на базе Tesseract.

---

## 📋 Требования

- Python 3.10+
- Tesseract OCR 5.x с языковыми пакетами (`rus`, `eng`)
- Poppler (для обработки PDF)
- NVIDIA GPU с поддержкой CUDA *(опционально, для нейросетевых моделей)*

## 📁 Структура проекта

```
ocr-service/
├── main.py                    # точка входа FastAPI
├── tesseract_config.py        # конфигуратор Tesseract OCR
├── vlm_ocr_config.py          # конфигуратор Qwen2-VL
├── summarizer_config.py       # конфигуратор ruT5

├── img_preprocess_utils.py    # предобработка изображений
├── postprocessing.py          # постобработка текста

├── templates/                 # HTML-шаблоны
├── static/                    # CSS, JavaScript
└── models/                    # локальные веса моделей
```
